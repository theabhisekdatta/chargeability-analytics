| Agent                    | Responsibility                                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------------------------- |
| **Planner Agent**        | Understands the user's question and decides which tools/agents to invoke.                            |
| **SQL Agent**            | Converts natural language into SQL, validates it, executes it, and retrieves data.                   |
| **RAG Agent**            | Searches staffing policies, utilization guidelines, SOPs, and project documents using vector search. |
| **Analytics Agent**      | Identifies trends, compares metrics, performs root-cause analysis, and generates business insights.  |
| **Report Agent**         | Produces executive summaries, tables, and visualizations suitable for management.                    |
| **Recommendation Agent** | Suggests actions such as reallocating resources, reducing bench time, or notifying managers.         |
